# Virtual-Ai-Assistant
Python-based AI Assistant with voice recognition and speech responses

## About the Project
This is a simple AI Assistant developed using Python. It allows users to interact through voice commands and text messages.

The assistant can perform basic tasks such as greeting users, telling the current time, checking weather information, and opening websites.

## Features
- Voice commands
- Text-based communication
- Text-to-speech responses
- Current time information
- Weather updates
- Open Google and YouTube
- Open Spotify
- Simple graphical interface using Tkinter

## Technologies Used
- Python
- Tkinter
- SpeechRecognition
- pyttsx3
- Requests
- Open-Meteo API

## Project Files
- `GUI.py` – Main graphical interface.
- `action.py` – Handles user commands.
- `speech_to_text.py` – Converts voice into text.
- `text_to_speech.py` – Converts text into voice.
- `weather.py` – Gets weather information.

## Installation

Install the required libraries:

```bash
pip install SpeechRecognition pyttsx3 requests pyaudio pillow
```

## Run the Project

```bash
python GUI.py
```
